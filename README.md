<summary><strong>Previous project: MedHealth</strong></summary>

<br />

MedHealth is a healthcare software project aimed at digitizing appointment booking, medical records, and health reminders.

The project was planned for Web, Mobile, and Desktop, with these goals:

- Make booking medical appointments more convenient.
- Help users store and review their medical histories.
- Provide reminders for appointments and follow-up care.
- Organize healthcare information and management workflows in one system.
